# DeepProtect 로컬 웹앱

Windows에서 [노트북 설치 가이드](../README-LAPTOP.ko.md)에 따라 설치합니다. [start-windows.cmd](../start-windows.cmd)를 더블 클릭하거나, 프로젝트 루트의 PowerShell에서 아래 명령을 실행합니다. 실행 창에 주소가 표시되면 브라우저에서 `http://127.0.0.1:8000/`을 엽니다. 작업 중에는 실행 창을 열어 둡니다.

```powershell
.\start-windows.cmd
```

다른 체크아웃에서는 `--models`, `--bank`, `--align-python`, `--predictor`로 준비된 경로를 지정할 수 있습니다. 서버는 127.0.0.1에만 바인딩합니다. 포트 8000을 사용 중이면 `--port 8001`처럼 다른 포트를 선택합니다.

## 실행 흐름

1. 25 MB 이하, 2,400만 픽셀 이하의 JPG 또는 PNG를 선택합니다. 사진에 얼굴이 여러 개 있으면 기존 정렬 스크립트가 가장 큰 얼굴을 선택합니다.
2. 정렬된 사진을 확인한 다음 **보호 이미지 만들기**를 누릅니다. 신원 혼합, 최대 1,200회 재구성, 800회 노이즈 보정, 워터마크 24개를 순서대로 실행합니다. 재구성은 이전과 같이 LPIPS 0.03에서 조기 종료할 수 있습니다.
3. JPEG 품질 85로 양쪽 이미지를 재인코딩한 뒤 로컬 ArcFace CosSim이 0.20 이하인 후보 중 SSIM 최고 결과를 제시합니다. 통과한 후보가 없으면 비교 완료와 기준 초과를 함께 표시하고, JPEG 85 CosSim이 가장 낮은 후보를 미리보기로 엽니다. 다른 후보를 선택해 내려받을 수도 있습니다.
4. 비교 슬라이더에서 정렬 원본과 보호 이미지를 확인합니다. MAE, SSIM, PSNR, LPIPS, PNG와 JPEG의 워터마크 전후 ArcFace 점수 및 PNG·JSON 다운로드가 제공됩니다.

한 번에 한 작업을 처리합니다. 같은 브라우저 탭을 새로 고치면 현재 작업을 다시 표시합니다. 작업 결과와 로그는 `outputs/web-jobs/<작업 ID>/`에 보관합니다. 서버 프로세스가 종료되면 진행 중인 작업을 다시 시작해야 합니다.

0.20은 이 앱에서 사용하는 후보 선택 기준입니다. 표에는 최적화에 사용한 것과 같은 로컬 ArcFace 모델의 점수가 표시됩니다. 다른 모델로의 전이 또는 실제 딥페이크 방어는 별도 실험입니다.

## 슬라이더 설정

**이번 튜닝**은 전체 LoRA 블록, 랭크 16, 재구성 최대 1,200회, 노이즈 보정 800회로 시작합니다. **공개 구현 기본값**은 b16·b32, 랭크 8, 재구성 최대 450회, LPIPS 목표 0.06, 추가 합성 가중치 학습과 노이즈 보정 끄기로 바뀝니다. 같은 사진으로 두 설정을 실행해 비교할 수 있습니다. [DeepProtect 논문 및 보충 자료](https://openaccess.thecvf.com/content/CVPR2026/html/Lee_DeepProtect_Proactive_Face-Swapping_Defense_using_Identity_Blending_and_Attribute_Distortion_CVPR_2026_paper.html)

각 항목 옆의 **?**에 마우스를 올리거나 키보드로 선택하면 의미와 영향을 볼 수 있습니다. 핵심 슬라이더 외에 신원 혼합, 재구성, 노이즈 보정, 워터마크의 고급 설정을 펼칠 수 있습니다. 노이즈 보정이 0회면 건너뜁니다. 자동 워터마크는 ε와 기본 반복 횟수를 기준으로 24개 조합을 만들며, 자동 모드를 끄면 고른 프롬프트로 한 번 적용합니다.

변환이 끝난 뒤 설정을 변경하고 **같은 사진으로 다시 실행**을 누르면 새 결과를 만듭니다. 이전 결과는 보관되며 **이전 실행 열기**로 이동할 수 있습니다. 실행마다 실제 적용 설정이 JSON에 함께 저장됩니다.

앱을 켜둔 채 업데이트했다면 실행 창에서 `Ctrl+C`를 누르고 다시 실행한 뒤 탭을 새로 고칩니다. 진행 중인 작업은 완료한 다음 재시작합니다.

[Windows에서 확인한 실행 범위](../README-LAPTOP.ko.md#검증-범위)
